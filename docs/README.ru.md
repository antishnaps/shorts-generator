# ContentBot Pro — Free

Бесплатная версия настольного генератора видео с открытым исходным кодом.
Активация, лицензионный сервер и покупка программы не нужны.

## Быстрый запуск (Windows)

1. Установите **Python 3.12 x64** с python.org. Это версия, на которой проверен этот пакет.
2. Распакуйте архив в отдельную папку с правом записи. Не накладывайте его на коммерческую установку.
3. Запустите `start.bat`. При первом запуске он создаст локальное окружение и установит зависимости из PyPI.
4. В настройках укажите **свои** ключи нужных сервисов. Ключи автора не распространяются.

Вручную:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для проверки установки: `.\.venv\Scripts\python.exe main.py --smoke-test`.
FFmpeg предоставляется зависимостью imageio-ffmpeg; для полного набора возможностей
можно установить FFmpeg и ffprobe отдельно и добавить их в PATH.
Для скачивания с YouTube нужен поддерживаемый yt-dlp JavaScript runtime
(например, Node.js или Deno); программа не устанавливает его автоматически.

## Что включено

Генерация и монтаж видео, локальные материалы, YouTube, Pexels, Pixabay,
Wikimedia Commons, озвучка, субтитры, эффекты, очередь, серии и опциональная
авторизация собственных YouTube-каналов. Доступность внешних сервисов зависит
от их правил, региона, квот и ваших учётных данных.

Gemini нужен для автоматической генерации текста и ряда интеллектуальных
функций. Edge TTS выбран по умолчанию для озвучки, но требует интернета и
может быть недоступен. Gemini TTS, генерация изображений, Veo и HeyGen могут
тарифицироваться поставщиками. **Программа бесплатна; внешние API не обещаются
бесплатными.** Проверяйте квоты и стоимость в кабинетах сервисов.

Загрузка готовых роликов на YouTube и аналитика требуют отдельной авторизации
вашего аккаунта. OAuth client JSON необходимо получить в своём Google Cloud
проекте; файл автора не включён. Фоновая публикация по умолчанию не настроена.

## Структура

- `main.py`, `core/`, `gui/` — приложение.
- `assets/branding/` — программно созданный знак и иконка.
- `config.json.template` — безопасный пример; `config.json` создаётся при запуске.
- `tests/` — выбранные автономные регрессионные проверки.
- `tools/` — воспроизводимый генератор иконки.
- `LICENSE`, `THIRD_PARTY_NOTICES.md` — лицензия и сведения о зависимостях.
- `RELEASE_MANIFEST.json` — список файлов и контрольные суммы исходного пакета.

Логи, кэш, готовые ролики, музыка, модели распознавания и пользовательские
изображения в архив не входят. Рабочие папки появляются при использовании.
Музыку и оверлеи добавляйте самостоятельно; права на сторонний контент
не предоставляются вместе с программой. Некоторые языки требуют установки
подходящих системных шрифтов. Vosk-модели при необходимости загружаются отдельно.

## Безопасность и права на материалы

Не публикуйте `config.json`, `.env`, cookies, OAuth-токены, логи и исходники
пользовательских видео. Не выдавайте доступ к своим аккаунтам другим пользователям.
Программа обращается к выбранным внешним API; отправляемые тексты и материалы
обрабатываются по правилам соответствующего поставщика.

Используйте только материалы, на которые имеете права. Для Wikimedia проверяйте
лицензию и требования атрибуции конкретного файла. Поиск/скачивание из YouTube
не означает разрешение на повторную публикацию. Доступность API и правомерность
использования контента — разные вопросы.
